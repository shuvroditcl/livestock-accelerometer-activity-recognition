# livestock-accelerometer-activity-recognition
End-to-end IoT wearable sensor &amp; time-series activity recognition pipeline using 25Hz tri-axial accelerometer telemetry (11,319 samples, 123 features). Benchmarks MLP, Balanced SVM, and Random Forest with leakage-free GroupShuffleSplit, PCA, LDA, and ANOVA feature selection—achieving 92.0% test accuracy and 0.92 Weighted F1.
